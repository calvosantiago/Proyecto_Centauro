1. Resumen Ejecutivo

Centauro es un agente de Inteligencia Artificial diseñado para auditar transcripciones de ventas de forma automática, estricta y escalable. A diferencia de un chat genérico, Centauro utiliza una arquitectura RAG (Retrieval-Augmented Generation) para garantizar que cada evaluación se base exclusivamente en los manuales oficiales de la organización.

3. Seguridad y Privacidad (Módulo GDPR)

El sistema incorpora un módulo estricto de privacidad (privacy.py) que actúa como cortafuegos de datos personales. Este proceso ocurre localmente en el servidor antes de realizar cualquier llamada a la API de OpenAI.

🔐 Mecanismo de Redacción: Los datos sensibles se detectan mediante expresiones regulares (Regex) y se sustituyen por tokens anónimos (ej: [REDACTED_PHONE]). El LLM nunca ve los datos reales.

Datos Protegidos:

  • Emails: Detecta patrones de correo electrónico.
  • Teléfonos: Detecta formatos nacionales (+34) e internacionales.
  • DNI/NIE: Detecta patrones de identificación española (8 dígitos + letra / X,Y,Z + 7 dígitos).
  • IBAN: Detecta cuentas bancarias españolas.

Nota: El modelo de IA es capaz de evaluar si el asesor "confirmó el DNI" viendo el token [REDACTED_DNI], manteniendo la funcionalidad de auditoría sin comprometer la privacidad.

4. Valor Estratégico: ¿Por qué un Agente Propio?

Comparativa entre el desarrollo de Centauro (Python/API) frente al uso manual de herramientas web (ChatGPT/Gemini).

Característica Chat Web (Manual) Agente Centauro (Automático)
Escalabilidad Baja. Requiere copiar/pegar 1 a 1. Industrial. Procesa miles de archivos sin intervención humana.
Privacidad Riesgo alto (se envían datos al chat). Control Total. Sanitización local antes de salir a la nube.
Precisión (RAG) Sufre alucinaciones con textos largos. Quirúrgica. ChromaDB recupera solo la regla exacta necesaria.
Datos (Output) Texto no estructurado. Base de Datos (JSON). Permite analítica masiva (Power BI).
Integración Aislado en el navegador. Conectable. Se integra con Outlook, Teams y SharePoint.
