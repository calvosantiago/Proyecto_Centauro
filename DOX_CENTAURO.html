1. Resumen Ejecutivo

Centauro es un agente de Inteligencia Artificial diseñado para auditar transcripciones de ventas de forma automática, estricta y escalable. A diferencia de un chat genérico, Centauro utiliza una arquitectura RAG (Retrieval-Augmented Generation) para garantizar que cada evaluación se base exclusivamente en los manuales oficiales de la organización.

3. Seguridad y Privacidad (Módulo GDPR)

El sistema incorpora un módulo estricto de privacidad (privacy.py) que actúa como cortafuegos de datos personales. Este proceso ocurre localmente en el servidor antes de realizar cualquier llamada a la API de OpenAI.

🔐 Mecanismo de Redacción: Los datos sensibles se detectan mediante expresiones regulares (Regex) y se sustituyen por tokens anónimos (ej: [REDACTED_PHONE]). El LLM nunca ve los datos reales.

Datos Protegidos:

  • Emails: Detecta patrones de correo electrónico.
  • Teléfonos: Detecta formatos nacionales (+34) e internacionales.
  • DNI/NIE: Detecta patrones de identificación española.
  • IBAN: Detecta cuentas bancarias españolas.

Diccionario de Componentes

Archivo / Módulo Responsabilidad y Función
main.py El Orquestador. Es el punto de entrada. Busca archivos nuevos, limpia formatos sucios (VTT) y coordina a los demás módulos.
centauro/privacy.py El Escudo de Seguridad. Contiene las RegEx (Expresiones Regulares) para detectar y ocultar DNI, teléfonos y emails antes de procesar nada.
centauro/analyze.py El Cerebro Analítico. Construye el Prompt maestro. Define las instrucciones para el LLM, inyecta el contexto recuperado y gestiona la lógica de inferencia de hablantes.
centauro/rag.py La Memoria (RAG). Se encarga de hablar con ChromaDB: trocea los manuales (chunking), los indexa y realiza las búsquedas semánticas.
centauro/llm_client.py El Conector y Contable. Gestiona la conexión con la API de OpenAI. Calcula y registra en un CSV el coste exacto (tokens) de cada ejecución.
centauro/schema.py El Contrato de Datos. Define la estructura obligatoria del JSON (clases Pydantic). Evita que la IA invente campos que no existen.
centauro/config.py Configuración Global. Centraliza rutas de carpetas, nombres de modelos y variables de entorno.
outputs/control_gastos.csv Log Financiero. Archivo autogenerado que registra la fecha, hora, archivo procesado y coste en dólares de cada operación.
