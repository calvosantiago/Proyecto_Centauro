🦄 Proyecto Centauro: Manual Técnico Integral

Versión: 2.1 (Deep Dive API & Prompt) | Última Actualización: Diciembre 2025

1. Resumen de Arquitectura

Centauro es un sistema de auditoría automática basado en RAG (Retrieval-Augmented Generation) y validación determinista. Su objetivo es transformar transcripciones de ventas no estructuradas en reportes de calidad puntuados matemáticamente.

El flujo de datos sigue una estricta política de "Confianza Cero" en la IA generativa, utilizando una capa de código Python ("Sheriff") para validar cada afirmación contra el audio real.

2. Anatomía del Prompt y Conexión API

El núcleo de la inteligencia de Centauro reside en cómo se comunica con OpenAI. No es un chat simple; es una inyección de contexto estructurada.

2.1. Conexión API (llm_client.py)

Este módulo gestiona el "handshake" con OpenAI. Se ha configurado para eliminar la creatividad y maximizar la precisión analítica.

  • Modelo: gpt-4o-mini (Optimizado para costes y alta velocidad).
  • Temperatura: 0.0.
    Justificación: Necesitamos determinismo. Ante el mismo input, la IA debe dar siempre el mismo output. No queremos "creatividad" en una auditoría.
  • Response Format: { "type": "json_object" }. Forzamos a la IA a devolver exclusivamente JSON válido, evitando texto introductorio.
  • Control de Costes: El script calcula los tokens de entrada/salida y registra el gasto en outputs/control_gastos.csv automáticamente.

2.2. Ingeniería del Prompt (analyze.py)

Utilizamos una estrategia de "Contenedores XML" para separar las instrucciones de los datos, evitando alucinaciones por contaminación de contexto.

graph TD subgraph "System Message (Instrucciones)" A[Rol: Auditor Estricto] B[Reglas Anti-Alucinación] C[JSON Schema Obligatorio] D[" (Contexto RAG)"] end subgraph "User Message (Datos)" E[" (Transcripción Sanitizada)"] end A --> API B --> API C --> API D --> API E --> API[OpenAI API Request]
Estrategia "Blind Extractor":
Le decimos a la IA: "Tus fuentes son exclusivamente las etiquetas XML. El texto en <MANUAL> son las reglas, pero NO puedes copiar texto de ahí. El texto en <AUDIO_REAL> es tu única verdad. Si copias texto que no está en el audio, fallarás."

3. Matriz de Evaluación (Las 6 Fases)

Centauro no evalúa "en general". Divide la llamada en 6 bloques obligatorios. La IA debe rellenar cada bloque, y el código Python (Sheriff) valida la evidencia.

Fase Importancia Lógica de Evaluación (Qué busca el Prompt)
1. INICIO BAJA Busca saludos cordiales ("Hola", "Buenos días", "Soy Paola").
Tolerancia: Si la grabación empieza cortada, no penaliza gravemente.
2. SONDEO ALTA Preguntas Abiertas: Busca interrogantes sobre el perfil, situación laboral o motivación del alumno.
Criterio: Con 1 o 2 preguntas relevantes es suficiente.
3. ARGUMENTACIÓN ALTA Lógica "O" (Inclusiva): No exige todo el manual. Valida si menciona Ranking O Metodología O Online O Partners.
Objetivo: Verificar que aportó valor, independientemente del argumento usado.
4. OBJECIONES / PRECIO ALTA Bolsa de Conceptos Económicos: No busca una cifra fija. Busca palabras como "Inversión", "Euros", "Beca", "Descuento", o cifras variables.
Objetivo: Detectar negociación o explicación de precios, sea cual sea el importe.
5. CIERRE ALTA Siguientes Pasos: Busca compromiso. Palabras clave: "Comité", "Enviar DNI", "Documentación", "Tarjeta", "Pago".
6. LEGAL MEDIA Coincidencia Estricta: Busca raíces de palabras legales: "Grabar", "Calidad", "Monitorizada".
Sheriff: Si no aparecen estas palabras exactas, marca como NO CUMPLE.

4. Metodología de Validación (Sheriff 4.1)

Una vez la IA genera el reporte JSON, entra en acción el script de validación determinista en Python.

Algoritmo "Token Overlap"

El Sheriff no compara frases exactas (que fallan por errores de transcripción como "ehh" o "esteee"). Compara Bolsas de Palabras:

  1. Limpieza: Se eliminan stopwords (el, la, de), puntuación y símbolos de moneda (€, $).
  2. Comparación: Se extraen las palabras clave de la evidencia citada por la IA (ej: ['precio', '5000', 'euros']).
  3. Búsqueda: Se verifica si esas palabras existen en la transcripción original.
  4. Umbral: Si más del 60% de las palabras clave están presentes, se acepta el criterio. Si no, se marca como ALUCINACIÓN.
